# Draw the Fence

The built Draw the Fence site (NEIS Center, Yards & Fences decision tool), served by GitHub Pages at
`/draw-the-fence/`. This repository holds build output only: the source is `dashboard/src/fence/` in
Opportunity_Security_Indices (branch `feat/yards-fences`). Rebuild with `VITE_BASE=/draw-the-fence/ npm run build:fence`
and `node scripts/prepare-fence-pages.mjs <this-folder>`, then commit and push.
